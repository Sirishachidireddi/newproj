# 🛒 E-Commerce Website

A modern and responsive **Full Stack E-Commerce Website** developed using **HTML, CSS, JavaScript, Java, and Spring Boot**. This project demonstrates the implementation of frontend and backend technologies to build an online shopping platform with product browsing, cart functionality, and user interaction.

---

# 🚀 Features

## 👨‍💻 Frontend Features

* Responsive and modern UI design
* Product listing page
* Product categories section
* Shopping cart functionality
* Signup page
* Dynamic content rendering using JavaScript
* Mobile-friendly layout
* Interactive user experience

## ⚙️ Backend Features

* Spring Boot backend application
* REST API support
* Maven project configuration
* Scalable project structure
* Backend service integration

# 💻 Frontend Setup

### Run Frontend

1. Open the `ecommerce front` folder.
2. Open `index.html` in your browser.

OR

Use VS Code Live Server:

```bash
Right Click → Open with Live Server
```

---

# 🔧 Backend Setup

## Prerequisites

Make sure the following are installed:

* Java 21+
* Maven
* IDE (IntelliJ IDEA / Eclipse / VS Code)

---

## Run Backend Server

Navigate to backend folder:

```bash
cd ecommerce-back
```

Run the Spring Boot application:

```bash
mvn spring-boot:run
```

OR run the main Spring Boot application class directly from IDE.
